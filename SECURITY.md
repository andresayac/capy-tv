# Security

If you find a vulnerability in Capy TV (the apps or the sync server), please report it in private:
on this repository, **Security → Report a vulnerability**. Please do not open a public issue for it.

Say what is affected, how to reproduce it, and what it lets someone do. You will get an answer as
soon as it has been looked at, and the fix will be released before the report is made public.

The sync server keeps only end-to-end encrypted data: a report that the server can read what an
account stores is especially welcome.
